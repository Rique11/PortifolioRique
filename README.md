# Portfólio — Henrique Cois

Portfólio pessoal desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Deploy na Vercel

Importe o repositório na Vercel. O projeto já inclui a configuração de build e saída para publicação como site estático.
